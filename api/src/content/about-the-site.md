# About this site

This site is a project of the [Human Rights Data Analysis Group
(HRDAG)](https://hrdag.org), a non-profit, non-partisan organization that
applies rigorous science to the analysis of human rights violations around
the world.

Everything shown here is based on **publicly available data**: the stop data
that California law enforcement agencies are required to collect and report
under the Racial and Identity Profiling Act (RIPA), published by the
California Department of Justice through the [OpenJustice Data
Portal](https://openjustice.doj.ca.gov/data), along with demographic data
from the U.S. Census Bureau's American Community Survey. HRDAG compiled the
data into a single database covering 2018--2024 and built this site to make
it explorable. For details about the underlying data --- what it contains,
how it is collected, and its limitations --- see [About the RIPA Stop
Data](about-the-data).

The full pipeline --- downloading, cleaning, loading, and this web
application --- is open source and available in the
[HRDAG/ripadb repository on GitHub](https://github.com/HRDAG/ripadb). The
repository documents every transformation applied to the published data, so
all numbers shown on this site can be reproduced from the original sources.

Questions, corrections, and suggestions are welcome --- please [open an
issue on GitHub](https://github.com/HRDAG/ripadb/issues).
